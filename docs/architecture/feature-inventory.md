# Feature inventory and disposition

> **Current staged-search delta — ADR-0017 (2026-10-16):** the distinct opt-in native public transport, in-budget native/transition read-only identity, selected UTF-16/literal contract, scoped BM25/stable pre-limit ties, bounded owned JSON, aggregate-only metrics, offline rebuild and local load/network/HTTP proofs are implemented. It is **disabled by default**, with no production routing, UI/caller selection or legacy removal. Earlier statements below that transport/scoring are unimplemented describe the prior milestone and are superseded by the [current candidate contract and release boundary](../operations/public-search-candidate.md). Selected 200-UTF-16 native validation differs from installed Zod 4.5.4 scalar counting; no exact Unicode parity claim.

**Whole-backend target update:** see [the production readiness ledger](../production-readiness.md), [machine capability matrix](../production-capabilities.json) and read-only `scripts/backend-readiness-inventory.py`. Current discovery finds 34 native route declarations versus 164 legacy handler declarations plus dynamic auth/MCP; counts are not parity. Native-only authority, RFC3339 wire dates, explicit search BFF/UI and local portable replica primitives are now implemented, not complete whole-backend migration.

This inventory is based on source inspection, not README claims. “Implemented” means implemented in the Rust workspace at `rust/`; it does **not** mean the TypeScript capability can yet be switched off.

## Intentional API migration implications

The current Hono endpoints are not duplicated verbatim. The Rust endpoints are versioned under `/v1`, return `{ "data": ... }` on success and RFC 9457 Problem Details on feature, JSON, routing, method, body-limit and timeout failures, and require `expected_revision` for page updates. See [`../api/openapi.v1.yaml`](../api/openapi.v1.yaml) and [`../migration/api-compatibility.md`](../migration/api-compatibility.md).

No existing endpoint should be routed to Rust until its row in this inventory is marked **implemented** and has compatibility/reconciliation tests.
