# Native public-search compatibility matrix

**Current:** opt-in native public candidate implemented/tested, disabled by default; current production authority and Orama/Qdrant remain unchanged pending reviewed release. See [ADR-0017](decisions/0017-public-search-contract-and-ranking-privacy.md), [candidate operations](../operations/public-search-candidate.md) and [verification](../verification-report.md).

Member management `/v1/projects/{project_id}/search` is not public delivery. The distinct candidate is `/v1/public/sites/{project_id}/search`, explicitly gated by `NIBLEAF_PUBLIC_SEARCH_ENABLED=false` by default. No production route, automatic legacy fallback or shadow mode is installed by this source change.

## Verified source inventory

- Legacy HTTP/schema: `apps/server/src/modules/public/sites/handlers.ts`, `packages/validators/src/index.ts`; installed Zod behavior is now executed on supported Node rather than inferred from `.max` spelling.
- Selection/live overlay/search/analytics: `apps/server/src/actions/sites.ts`; cache/reader scope: `apps/server/src/lib/{search-cache,published-config}.ts`, `apps/server/src/actions/reader-access.ts`; Orama and optional hybrid: `packages/search/src`, `apps/server/src/lib/ai-search`, `packages/qdrant`.
- Native: search `public_api.rs`, `published.rs`, `query/{scoped_rank,public_tests}.rs`, execution driver, source/registry/runtime validators; API composition `optional_identity.rs`; identity read-only shared session checks.
- Actual proof: eight flagged DB commands, 39 public HTTP assertions, CPU units, TCP blackhole/resume/forced-termination rounds, load/offline rebuild, supported-Node adapter tests/types. Scope/counts/results are in the current report; hosted CI/container/production execution is not claimed.
