## Security review rules for deferred slices

A deferred capability is not approved for porting without these reviews:

- identity: cookies, CSRF, session rotation/revocation, OAuth state/PKCE, OTP anti-enumeration, rate limiting;
- integrations/imports: SSRF DNS and connection checks, redirects, webhook signature/replay, encrypted credential rotation;
- storage/exports: authorization before presigning, content/size validation, archive traversal, bounded browser resources, retention;
- public readers: private site/audience decisions on every response, JWT issuer/audience/key rotation/replay control;
- APIs: object-level authorization and cross-tenant negative tests, body/query limits, no SQL/provider error exposure.
